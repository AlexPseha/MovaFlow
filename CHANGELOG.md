# Changelog

Всі помітні зміни у проєкті MovaFlow документуються у цьому файлі.

## [1.1.0] - 2026-11-03

### Додано
- **Курований білий список коротких слів (ShortWords.cs, WordAnalyzer.cs)**: впроваджено окрему систему `ShortWords` для оцінки 1–3 літерних слів, що назавжди усуває проблему хибних перемикань на кшталт `зу` → `pe`.
- **Контекст рядка (LanguageContext.cs, WordAnalyzer.cs)**: збереження мовної історії останніх 3–5 слів рядка для запобігання випадковим стрибкам розкладки при швидкому друку.
- **Конвертація виділеного тексту через хоткей (SelectedTextConverter.cs, KeyboardHookManager.cs)**: підтримка комбінації `Ctrl+Shift+L` для миттєвої зміни мови та розкладки виділеного фрагмента в будь-якому додатку Windows.
- **Автоматична пропозиція додати у винятки (ExceptionPromptManager.cs, TrayApplicationContext.cs)**: показ сповіщення в треї при подвійному скасуванні автозаміни одного й того ж слова Backspace-ом із пропозицією миттєво додати його до списку виключень.
- **Апаратний індикатор Caps Lock (CapsLockIndicator.cs, SettingsForm.cs)**: опціональна індикація активної української розкладки через світлодіод Caps Lock на клавіатурі.
- **Журнал діагностики (DebugLogger.cs, TrayApplicationContext.cs)**: додано безпечний логер системних подій клавіатури у файл `%APPDATA%\MovaFlow\debug.log` та пункт швидкого перегляду журналу в трей-меню.
- **Виправлення залиплого Shift (SmartTypography.cs, WordAnalyzer.cs)**: автоматичне виправлення слів із двома великими літерами на початку (наприклад, «ПРивіт» → «Привіт», «ТОму» → «Тому»).
- **Керування новими функціями в налаштуваннях (SettingsForm.cs, Strings.cs, ExclusionManager.cs)**: додано чекбокси для контексту рядка, конвертації виділеного, автоматичних винятків та Caps Lock LED.
- **Тестування (UnitTests.cs, live_typing_test.ps1)**: розширено набір автотестів до 118 тестів (100% успішне проходження).
- **Документація (README.md, README.en.md)**: оновлено опис можливостей, додано таблиці хоткеїв та інструкції щодо нових модулів.

### Виправлено
- **Атомарний відпуск Shift при вставці Unicode (InputSynthesizer.cs)**: усунуто блокування вставки спецсимволів `«`, `»`, `“`, `”` додатками Windows (Telegram, Chrome, Word тощо) шляхом атомарного відпуску клавіші `Shift` перед передачею `KEYEVENTF_UNICODE` та повернення її стану у тому ж пакеті `SendInput`.
- **Розпізнавання лапок та визначення фокусу (KeyboardHookManager.cs, SystemLayoutSwitcher.cs)**: впроваджено подвійне розпізнавання лапок за `typedChar` та кодами клавіш `Shift + 2` (кирилиця) та `Shift + '` (латиниця), точне визначення `hkl` через `GetGUIThreadInfo` для фокусного контролу каретки.
- **Підтримка одинарної лапки без Shift та збереження апострофа (SmartTypography.cs, KeyboardHookManager.cs)**: клавіша `'` без Shift на початку або в кінці слова автоматично стає `«` / `»` або `“` / `”`, але гарантовано залишається апострофом усередині слів (`м'ясо`, `п'ять`, `don't`).
- **Спецсимволи та кодування типографіки (SmartTypography.cs)**: усі типографські символи переведені на стабільні Unicode escape-послідовності (`\u00AB`, `\u00BB`, `\u201C`, `\u201D`, `\u2014` тощо).

## [1.0.1] - 2026-11-02

### Додано
- **Слова-виключення (ExclusionManager.cs, SettingsForm.cs)**: підтримка власного списку слів-виключень (Stop-words), абревіатур та термінів (`ННГ`, `API` тощо), які ігноруються аналізатором розкладки в обох напрямках.
- **Опція Revert on Backspace у налаштуваннях (SettingsForm.cs, KeyboardHookManager.cs)**: чекбокс на вкладці «Загальні» для вмикання/вимикання автоматичного повернення розкладки при натисканні Backspace одразу після автозаміни.
- **Інтерфейс налаштувань (SettingsForm.cs, Strings.cs)**: нова секція для додавання та видалення слів-виключень, скорочено заголовок до «Виключені слова:», розширено клієнтську ширину форми до 740 px та вирівняно колонки по 224 px.

### Виправлено
- **Збереження слів-виключень (ExclusionManager.cs)**: виправлено метод `Save()`, який затирав передані зі списку слова порожнім масивом замість оновлення внутрішніх колекцій.
- **Стабільність перемикання на льоту (KeyboardHookManager.cs)**: відновлено роботу on-the-fly автозаміни під час безперервного набору, забезпечено чисте скидання буфера після заміни для запобігання дублюванню при подальшому натисканні пробілу/Enter.
- **Захист CamelCase / PascalCase (WordAnalyzer.cs, NgramDetector.cs)**: усунено помилкове визначення 4 приголосних на межах слів у CamelCase (наприклад, `OrdersWithTrips`) та заборонено fallback-конвертацію в кирилицю, якщо результат відсутній у словнику.
- **Захист 2-літерних кириличних сполучень (WordAnalyzer.cs)**: заборонено примусову конвертацію 2-літерних сполучень (наприклад, `зу` -> `pe`) лише за наявністю короткого англійського слова.
- **Скрипт збірки та .gitignore (build_and_publish.ps1, .gitignore)**: прибрано генерацію дубліката `MovaFlow.exe` у корінь, додано `graphify-out/` до `.gitignore`.
