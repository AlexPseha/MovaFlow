# MovaFlow

🇺🇦 **Українська** · [🇬🇧 English](README.en.md)

Безкоштовний, легкий та приватний помічник для набору тексту на Windows - автоматичне виправлення розкладки, частотні словники, захист паролів і повна локальна автономність.

MovaFlow сам перемикає розкладку, коли слово набрано не тією мовою (`ghbdsn` → `привіт`, `cghfdb` → `справи`, `rfr ltkf` → `как дела`), синхронізує системну мову активного вікна Windows 10/11 (Блокнот, Chrome, Telegram, VS Code тощо) та підтримує як режим виправлення «на льоту», так і після натискання пробілу. Усе працює на вашому ПК: без облікових записів, ключів, сторонніх серверів і телеметрії - 100% офлайн.

## Можливості

### Розкладка та інтелект набору
* **Виправлення «на льоту» (On-The-Fly):** вже на 3–4 літері MovaFlow бачить, що слово набирається не тією розкладкою (`ghb…`), і плавно перемикає його прямо під час друку.
* **Виправлення за роздільниками:** слово перевіряється після натискання Пробілу, Tab, Enter або розділового знака: `ghbdsn?` миттєво стає `привіт,`.
* **Вбудовані частотні словники:** по 25 000 найпопулярніших слів для української (UKR), англійської (ENG) та російської (RUS) мов (корпус HermitDave). Швидкість пошуку в префіксному дереві (Trie) - менше 1 мікросекунди.
* **Повна підтримка абетки:** коректна обробка специфічних літер `і`, `ї`, `є`, `ґ`, апострофа та літер `б`, `ю` (навіть при наборі через клавіші `,` та `.`).
* **Надійне системне перемикання Windows 11:** гарантована зміна активної системної розкладки у сфокусованому вікні (WinUI 3, UWP, Chromium, Electron, Win32).
* **Гнучкі режими конвертації:**
  * *Двосторонній:* автоматичне розпізнавання всіх увімкнених мов.
  * *Тільки з української в англійську.*
  * *Тільки з англійської в українську.*

### Безпека та захист паролів (Security-First)
* 🛡️ **Захист паролів:** MovaFlow автоматично розпізнає парольні поля через Windows UI Automation (`IsPassword == true`) та нативний стиль `ES_PASSWORD`. У момент фокусу на парольному полі перехоплення клавіш миттєво вимикається, а буфер пам'яті занулюється.
* 🚫 **Програми-виключення:** автоматичне призупинення в терміналах (`cmd.exe`, `powershell.exe`, Windows Terminal), середовищах розробки та менеджерах паролів (KeePass, 1Password, Bitwarden).
* 🌐 **Сайти-виключення:** безпечний набір на банківських сайтах (`privat24.ua`, `monobank.ua`) - MovaFlow автоматично зупиняє аналіз, коли активна відповідна вкладка браузера.
* 🔒 **100% офлайн і приватність:** жодного запису на диск, жодних викликів мережі, нуль телеметрії. У пам'яті зберігається лише короткий кільцевий буфер (до 64 символів), який автоматично стирається після завершення слова.

### Інтерфейс і керування
* **Зручний системний трей:** акуратний значок біля годинника, статус роботи, лічильник виправлених слів, швидка пауза та вибір розкладок.
* **Нова векторна іконка «Flat Fluent M-Flow»:** чіткий повнорозмірний дизайн, оптимізований під темну та світлу панелі завдань Windows 11.
* **Вікно налаштувань:**
  * Вибір мови інтерфейсу в один клік (Українська / English).
  * Увімкнення та вимкнення потрібних розкладок (UKR, ENG, RUS).
  * Керування списками виключених програм і веб-сайтів.
  * Автозапуск разом із Windows.

## Приватність

MovaFlow створений з акцентом на приватність:
1. **Жодного збору даних:** програма не відправляє жодного байта інформації в інтернет.
2. **Жодного збереження тексту:** історія набору тексту не записується у файли або реєстр.
3. **Захист пам'яті:** дані існують виключно в оперативній пам'яті поточного процесу та стираються після кожного виправлення або натискання Enter / Escape.
4. **Відкритий вихідний код:** кожен рядок коду доступний для аудиту в цьому репозиторії.

## Для розробників

Проєкт написаний на **C# (.NET 9.0 Windows Forms / Win32 API)** з модульною архітектурою:

```bash
# Клонування репозиторію
git clone https://github.com/AlexPseha/MovaFlow.git
cd MovaFlow

# Запуск вбудованого набору автоматичних тестів (41 тест)
dotnet run -- --test

# Збірка релізного MovaFlow.exe та інсталятора MovaFlow-Setup.exe
powershell -ExecutionPolicy Bypass -File .\build_and_publish.ps1
```

### Структура коду
* `src/Core/` - статистичні алгоритми розпізнавання, N-грами, Trie-словник, матриця транслітерації.
* `src/Input/` - низькорівневий хук клавіатури (`WH_KEYBOARD_LL`), Win32 синтез вводу та перемикання системної мови.
* `src/Security/` - детекція полів паролів через Windows UI Automation, білі/чорні списки додатків і сайтів.
* `src/Localization/` - двомовні тексти інтерфейсу (Українська та English).
* `src/UI/` - контекстне меню трею Windows (`TrayApplicationContext`) та вікно налаштувань (`SettingsForm`).
* `installer/` - окремий автономний проєкт майстра встановлення `MovaFlow-Setup`.
* `resources/` - частотні словники та мультирозмірна іконка `movaflow.ico`.
* `tests/` - автономний тестовий стенд (`UnitTests.cs`), що перевіряє словники, виключення та локалізацію.
